# Hrishikesh Patil — Robotics Engineering Portfolio

A responsive React + TypeScript + Vite portfolio starter.

## Requirements
- Node.js 20 or newer recommended
- npm

## Run locally
1. Extract this ZIP file.
2. Open a terminal in the extracted `hrishikesh_robotics_portfolio` folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Production build
```bash
npm run build
npm run preview
```

## Personalize before publishing
- Edit `src/App.tsx` to replace placeholder email and social links with your real details.
- Add your resume PDF under `public/` and connect the Download CV button when ready.
- Replace project concepts with genuine project screenshots, repository links, demos, and results as you complete them.
- Update academic and work dates/details to match your final CV.

## Notes
- Project cards are intentionally marked In progress or Planned.
- The hero uses `public/watermarked_preview.mp4` as an autoplaying, muted, looping background video.
- Contact form has not been implemented; don't advertise it as functional until connected to a backend/form service.
